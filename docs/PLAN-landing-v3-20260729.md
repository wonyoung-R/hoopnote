## 1. 개정 배경 — 무엇이 왜 바뀌었나

### 1.1 제품 정의 전환 (가장 중요한 변화)

| | 기존 (현행 랜딩) | 신규 (v2 §1.1) |
|---|---|---|
| 대표 메시지 | "좋은 수업이 재등록의 증거로 남게 하세요" | "우리 아이 지금 어디 있나"에 원장님이 손대지 않아도 답이 가는 제품 |
| 핵심 가치 | 성장 기록 → 학부모 신뢰 → 재등록률 | 등하원 안심 → 학부모 문의(전화·카톡) 감소 |
| 근거 | (마케팅 가설) | 원장 미팅 실발언(07-28, 원영): "엄마들은 어쨌든 내 애가 도착하고 오고 이게 제일 중요한 거잖아... 갔는지 안 갔는지 이 걱정을 좀 덜어주는 거" |

**이 둘은 다른 제품입니다.** 재등록 자료는 학기 단위로 가끔 필요하지만, 등하원 안심은 매일 반복되는 마찰입니다. 원장이 실제로 지목한 문제(반복 전화·카톡 문의)를 정확히 겨누는 쪽이 신규 정의이므로, 랜딩의 **대표 메시지 자리는 안심 프레임으로 교체**하고 재등록/성장 리포트는 보조 메시지로 남깁니다(완전 삭제 아님 — §3 참조).

### 1.2 요금 전환

| | 기존 | 신규 (v2 §1.5) |
|---|---|---|
| 구조 | 재학생 구간별 정액 3티어 (100~299명 10만원대 / 300~499명 30만원대 / 500명↑ 50만원대) | 학생당 월 1,500원 · 하한 100,000원 · 상한 500,000원 |
| 포함 | 불명확 | 알림톡 발송료 + AI 사용료 포함(결제선생 수수료 제외) |
| 구현 상태 | 코드에 그대로 반영, 자진신고 방식 (`subscription-plans.ts`) | **계산 로직만 존재**(`usage-pricing.ts`), 실청구 경로 미연결. 최고 티어 549,000원은 신규 상한(50만원) **초과** |

**파급**: 하한이 10만원으로 낮아지면서 기존 랜딩(및 `guide-request.html` 학생 수 select — 100명부터 시작)이 사실상 배제하던 **30~99명 소규모 학원이 신규 진입 가능**해졌습니다. 이건 랜딩 구조뿐 아니라 리드 수집 폼 자체의 결함으로 이어집니다(§7 추가 발견).

### 1.3 AI 노출 제거 (v2 §1.3)

AI는 인프라이지 기능이 아니며 화면에 등장하지 않습니다. 특히 **알림장·학부모 메시지 문장은 AI 관여가 명시적으로 금지**됩니다. 현행 랜딩은 정확히 이 금지 영역(AI가 알림장 초안을 쓴다)을 대표 세일즈 포인트로 삼고 있어 구조적 충돌입니다. AI 언급 32건 중 18건이 구조적(섹션 전체·목업 통째)입니다.

### 1.4 신규 기능 (랜딩 미반영 0건)

출석 패드(키오스크), 의류 신청 폼, 동의 관리, 발송 신뢰성(보낸 내역)이 신규 스펙으로 확정됐고 round1-report 기준 **코드로는 구현됐으나 브랜치 상태**입니다(미머지·미배포). 셔틀은 기존에도 있었으나 랜딩에 독립 소개가 없었습니다.

### 1.5 경쟁 구도 (v2 §1.6)

온하이는 전 기능 무료, 전 종목, 출결 키패드 보유, **셔틀 없음**. 가격 경쟁은 성립하지 않으므로 요금 카피는 "저렴함"이 아니라 "예측 가능함"을 팔아야 하고(§5), 기능 카피는 "농구 전용 + 셔틀"의 깊이로 방어해야 합니다.

## 2. 타깃·페르소나 재정의

### 2.1 페르소나 분리 (TEAM_DNA User Lens 3.1)

| 페르소나 | 역할 | 랜딩에서의 위치 |
|---|---|---|
| **원장** | 결제자·의사결정자 | 랜딩의 1차 독자. 도입 안내서 CTA를 누르는 사람 |
| **코치** | 실사용자 | 랜딩 카피의 대상 아님(코치는 원장이 채용). 단 "코치가 버튼 하나로" 같은 문구는 원장에게 "코치 교육 부담이 적다"는 신호로 작동 |
| **학부모** | 수혜자 (실제 문제의 당사자) | 랜딩 문구가 묘사하는 문제의 주체. "학부모가 안심한다"는 곧 "원장에게 오는 문의가 준다"로 번역돼야 설득력이 생김 |
| **학생** | 수혜자 (등원 패드 조작자) | 랜딩 노출 최소 (아동 개인정보 원칙상 학생 개인 식별 정보 노출 금지) |

### 2.2 Want vs Need (원장 기준)

| | Want (원장이 표면적으로 말하는 것) | Need (근본 문제) |
|---|---|---|
| 기존 랜딩이 겨눈 것 | "학부모가 우리 학원을 더 신뢰했으면" | 재등록률 (분기·학기 단위, 저빈도) |
| **v2가 겨눈 것** | "관리가 편했으면" | **학부모의 반복 문의(전화·카톡) 감소** (매일, 고빈도 마찰) — 미팅 발언에서 직접 확인됨 |

저빈도 Want보다 고빈도 Need를 정확히 찌르는 게 v2 방향의 핵심 근거입니다. 재등록은 남기되(§3), 헤드라인 자리는 매일의 마찰 쪽으로 이동합니다.

### 2.3 신규 세그먼트 — 소규모 학원(30~99명)

가격 하한(10만원) 덕분에 수학적으로는 이미 진입 가능하지만, **적극적으로 유치할지는 별개의 영업 판단**입니다(§9-③). 이번 라운드에서 최소한으로 해야 할 일은 "가능한데 랜딩이 막아놓은" 상태를 푸는 것 — 구체적으로 `guide-request.html`의 학생 수 select가 100명 미만을 아예 선택할 수 없게 되어 있는 결함을 해소하는 것입니다(§7).

### 2.4 톤

[[feedback_hoopnote_persona_age]] 기준: 원장 연령대 20~40대(20~30대 다수), 채널은 인스타/릴스 주력·스레드·네이버 검색 보조. 톤은 "젊게" — 이번 개정에서도 유지. 안심 프레임은 톤을 무겁게 만들 위험이 있으므로("사고 예방" 식 불안 마케팅으로 흐르지 않도록) 헤드라인은 위협이 아니라 **편안함**으로 서술합니다(예: "물어보지 않아도 됩니다" O, "아이가 실종되면 어떡하죠" 류 공포소구 X).
